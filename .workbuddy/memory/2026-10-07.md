## CI/CD 工作流补全
- 分析项目架构：Python≥3.12 + uv 包管理；FastAPI/Uvicorn Web API(5555)；cx_Freeze 可执行构建；多阶段 Dockerfile + docker-compose；pytest 用例在 `src/testers/`(纯单元，无网络)。
- 现有 `.github/workflows/` 仅做发布/手动的「可执行产物构建」与「Docker 镜像推送」，缺少 push/PR 的自动测试/检查与真正的部署步骤。
- 新增 `.github/workflows/ci.yml`：push/PR 触发，jobs=lint(ruff) + test(矩阵 3.12/3.13 pytest src/testers) + docker-build(构建校验+import 冒烟)。
- 新增 `.github/workflows/deploy.yml`：release/manual 触发，构建推送多架构镜像(Docker Hub+GHCR) + SSH 部署(重建 douk 容器)。建议停用旧 Release_docker_image.yml / Manually_docker_image.yml 避免重复推送。
- 部署所需 secrets：DOCKERHUB_USERNAME, DOCKERHUB_TOKEN, DEPLOY_HOST, DEPLOY_USER, DEPLOY_SSH_KEY, DEPLOY_PORT(默认22)；建议服务器侧用长期 PAT 拉取 GHCR。
- 注意：action 版本号沿用了仓库既有约定(checkout@v7 / setup-uv@v9.0.0 等)；若实际 GitHub 环境无这些版本需下调到可用 major。
