# 无人值守部署

本仓库在官方代码基础上增加了无人值守启动能力：容器启动后不再出现语言选择、免责声明确认和功能菜单输入，可直接对外提供服务。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DOUK_UNATTENDED` | 自动判断 | `1` 强制无人值守；`0` 恢复官方交互行为；未设置时，未分配交互终端（容器、CI 等）自动启用 |
| `DOUK_RUN_COMMAND` | 空 | 启动后自动执行的菜单命令，见下表；留空时无人值守模式默认使用 `7` |
| `DOUK_COOKIE` | 空 | 抖音 Cookie，优先级高于 `Volume/settings.json` |
| `DOUK_COOKIE_TIKTOK` | 空 | TikTok Cookie，优先级同上 |
| `DOUK_LANGUAGE` | 空 | 界面语言，可选 `zh_CN` / `en_US` |

环境变量只影响本次运行，不会写回 `Volume/settings.json`。

## 常用运行模式

`DOUK_RUN_COMMAND` 的取值与主菜单序号一致，多个值用空格分隔、按顺序执行：

| 取值 | 含义 |
| --- | --- |
| `7` | Web API 模式，端口 5555，接口文档 `/docs`（默认） |
| `6` | 后台监听模式 |
| `5 2 1` | 终端交互模式 → 批量下载链接作品(抖音) → 手动输入作品链接 |
| `5 2 2` | 终端交互模式 → 批量下载链接作品(抖音) → 从文本文档读取链接 |

## 部署

```bash
docker compose up -d
```

`Volume` 目录必须持久化。该目录保存配置、数据库和下载文件；若不持久化，每次重建容器都会重新初始化，免责声明状态、下载记录和 Cookie 都会丢失。

## 安全提示

Web API 默认不校验令牌（`src/custom/function.py` 中的 `is_valid_token()` 直接返回 `True`），并且 `/settings` 接口会返回包含 Cookie 的全部配置。不要把 5555 端口直接暴露到公网，建议只绑定回环地址、限定在容器网络内访问，或前置反向代理做认证。

## GitHub Actions

仓库自带 `.github/workflows/Manually_docker_image.yml`，可在 Actions 页面手动触发构建并推送到 Docker Hub 与 GHCR。使用前需要配置仓库密钥 `DOCKERHUB_USERNAME`、`DOCKERHUB_TOKEN`；触发时填写 `custom_version`（例如 `5.8`）即可，否则会去查询最新 Release 标签。
